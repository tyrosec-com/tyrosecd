# Sicherheitslücken melden / Reporting security issues

Bitte melden Sie mögliche Sicherheitslücken **nicht** öffentlich, sondern per Mail an **info@tyrosec.com** mit dem
Betreff „Security“. Hilfreich sind: betroffene Version (`tyrosecd --version`), Beschreibung, Schritte zum Nachstellen.

- Wir bestätigen den Eingang innerhalb von 3 Werktagen und melden uns mit einer Einschätzung.
- Behobene Lücken nennen wir im [CHANGELOG](CHANGELOG.md); auf Wunsch mit Dank an die meldende Person.
- Prüfen und Melden ist nach der [Lizenz](LICENSE), Abschnitt 2.1, ausdrücklich erlaubt.

Please report suspected vulnerabilities privately to **info@tyrosec.com** (subject “Security”), including the affected
version (`tyrosecd --version`), a description and steps to reproduce. We acknowledge within 3 business days. Reviewing
and reporting is explicitly permitted by the [licence](LICENSE), section 2.1.
