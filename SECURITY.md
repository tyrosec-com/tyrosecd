# Reporting security issues

Please do **not** report suspected vulnerabilities publicly. Send them by email to **info@tyrosec.com** with the subject
“Security”. Helpful details: the affected version (`tyrosecd --version`), a description and steps to reproduce.

- We acknowledge receipt within 3 business days and follow up with an assessment.
- Fixed issues are listed in the [CHANGELOG](CHANGELOG.md); on request with credit to the reporter.
- Reviewing the code and reporting issues is explicitly permitted by the [licence](LICENSE), section 2.1.
